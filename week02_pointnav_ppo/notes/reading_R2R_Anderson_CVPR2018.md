# Vision-and-Language Navigation 任务评估与模型设计  
## 评估指标与数据集划分  
### 导航成功判定标准  
- 导航误差小于3米视为成功（允许约一个视角的误差，显著低于初始最小误差5米）  
- 不评估完整轨迹，因多数指令未规定具体路径  
- 要求智能体主动终止 episode 以识别目标位置，体现任务理解与后续任务就绪能力  
- 对比设置：引入“oracle 停止规则”——在轨迹中离目标最近点强制停止，用于解耦目标识别能力  

### 数据集划分策略  
- 测试集：18个场景，4,173条指令（目标位置不公开，仅通过评估服务器提交轨迹评分）  
- 验证集（未见环境）：11个新场景，2,349条指令（val unseen）  
- 训练/验证集（已见环境）：61个场景，划分为14,025条训练指令 / 1,020条验证指令（val seen）  
- 完全遵循 Matterport3D 数据集的划分范式 [11]  

## 智能体模型架构  
### 序列到序列（Seq2Seq）神经网络  
- 核心结构：LSTM 编码器-解码器 + 注意力机制 [6, 23, 34]  
- 输入：自然语言指令 $\bar{x} = \{x_1, x_2, ..., x_L\}$ 与初始图像观测 $o_0$  
- 编码器：逐词输入词嵌入，输出上下文向量 $\bar{h} = \{h_1, ..., h_L\}$；指令逆序输入提升效果 [49]  
- 解码器：每步输入当前图像特征 $o_t$ 与前一动作 $a_{t-1}$ 的拼接向量 $q_t$，维护历史记忆以应对部分可观测环境 [56]  

### 模型关键组件设计  
#### 动作空间简化  
- 限定为6类离散动作：左转、右转、上仰、下俯、前进、停止  
- 前进：始终移向视野中心最近的可达视角  
- 视角调整：左右/上下各旋转30度（离散化 heading & elevation）  

#### 多模态特征嵌入  
- 图像编码：ResNet-152（ImageNet预训练）提取均值池化特征向量  
- 动作编码：学习32维动作嵌入向量  
- 融合输入：图像特征与前一动作嵌入拼接为 $q_t$  

#### 注意力机制实现  
- 使用 Luong 全局对齐函数 [34] 计算指令上下文 $c_t = f(h'_t, \bar{h})$  
- 构建注意力隐藏状态 $\tilde{h}_t = \tanh(W_c[c_t; h'_t])$  
- 动作预测：$\mathbf{a}_t = \text{softmax}(\tilde{h}_t)$  
- 注：暂未引入视觉注意力，留待未来工作  

## 训练策略与实现细节  
### 两种训练范式对比  
- 教师强制（Teacher-forcing）[32]：训练时强制使用真实动作 $a^*_t$ 作为输入，但导致训练-测试分布偏移 [45, 32]  
- 学生强制（Student-forcing）：每步从模型输出分布中采样动作，等价于在线 DAgger [45] 或调度采样中的“始终采样” [8]  
- 实验发现：学生强制在已见环境表现更优，而调度采样效果差于学生强制  

### 实现超参数配置  
- 文本预处理：全小写、空格分词、过滤低频词（出现<5次）  
- 图像设置：640×480 分辨率，垂直视场角 60°  
- LSTM 隐藏单元：512；词嵌入维度：256；动作嵌入维度：32  
- 正则化：嵌入层/CNN特征/注意力模块 Dropout=0.5  
- 加速训练：预缓存所有 CNN 特征（因视角离散化）  
- 优化器：PyTorch Adam（含权重衰减），批量大小=100，固定迭代次数  
- 测试推理：贪心解码（greedy decoding）[44]；最终提交模型使用全部训练+验证数据训练  

## 基线方法与人类性能  
### 无学习基线  
- RANDOM：随机选择朝向后执行5次有效前进（不可前进时选右转）  
- SHORTEST：始终沿最短路径前往目标（Oracle 路径）  

### 人类基准  
- 采集方式：AMT 平台收集测试集1/3（1,390条）的人类轨迹  
- 交互方式：第一人称自由点击导航（提供完整场景与指令，信息量与智能体一致）  
- 质量控制：对停在目标3米内者发放奖金  

## 实验结果分析  
### 主要性能对比（Table 1）  
- 测试集成功率：RANDOM=13.2%，SHORTEST=9.93%，人类=86.4%  
- 学生强制 Seq2Seq：已见环境（Val Seen）达11.33%，未见环境（Val Unseen/Test）显著下降至8.39%/8.13%  
- Oracle 成功率（强制最优停止）：人类90.2%，学生强制最高18.3%，显示停止决策是主要瓶颈  
- 轨迹长度与导航误差：人类平均误差0.00m，智能体普遍>1.6m；SHORTEST 轨迹最短（~6m），RANDOM 最长（~10.2m）  
- 关键结论：在已见环境具备初步能力，但跨场景泛化（unseen environments）仍是巨大挑战

Table 1 展示了 R2R 数据集上各类导航方法的核心性能对比结果，具体体现为：
Success (%)：衡量模型是否成功抵达目标（最终位置距目标 < 3m）。
在已见环境（Val Seen）中，学生强制训练（student-forcing）模型达 38.6%；
在未见环境（Val Unseen / Test）中显著下降至 21.8% / 20.4%，凸显泛化能力严重不足；
人类表现高达 86.4%（Test），说明任务本身合理、指令质量高，但当前模型与人类差距巨大。
Oracle Success (%)：假设在轨迹中离目标最近处主动停止的理想成功率，反映路径探索质量。
Val Unseen 下为 52.9%（高于实际成功率 21.8%），表明模型常“路过目标却不停止”，停止决策是关键瓶颈。
Trajectory Length (m)：平均路径长度（单位：米），反映导航效率。
模型路径（9–10 m）接近最短路径（6–8 m），说明动作执行较合理，但存在冗余或绕行。
综上，Table 1 说明：R2R 任务极具挑战性，尤其在于跨场景泛化与适时停止决策；现有模型虽能学习基本导航逻辑，但远未达到实用水平。

Figure 7 展示了模型在训练过程中于已见环境（val seen）和未见环境（val unseen）上的验证损失、导航误差与成功率变化趋势。从中可得出以下结论与建议：
结论：
即使采用强正则化（dropout + weight decay），模型在未见环境上的性能迅速饱和，而在已见环境上持续提升；
这表明模型学习到的视觉指代（visual grounding）高度依赖训练场景，泛化能力弱，存在严重过拟合。
建议：
需发展更强的跨场景表征学习方法（如环境无关的视觉语言对齐、场景自适应模块）；
训练策略应更注重未见环境的早期评估与优化，而非仅追求已见环境指标提升；
探索数据增强、域随机化或合成-真实迁移等技术，缓解对特定建筑纹理/布局的依赖。
简言之：Figure 7 揭示了泛化瓶颈源于场景特异性过拟合，未来工作必须将“泛化”置于优化目标核心。
