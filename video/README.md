# 演示视频脚本（5–8 分钟）

## 提交要求

> "失败案例需附截图、轨迹图或短视频；最终报告及 5–8 分钟的演示视频"

## 视频结构

### 第一部分：问题概述（30 秒）
- **幻灯片**：PointGoal 导航定义 — "前往 (Δx, Δy)"
- **幻灯片**：三种失败类型：lost（迷路）、near_miss（擦肩而过）、bad_stop（停错位置）（附 DTG 数值）
- **旁白**："标准 PointNav PPO 在三种情况下会失败……"

### 第二部分：仿真实验（2 分钟）
- **屏幕录制**：TensorBoard 训练曲线（baseline 对比 stop_aware）
  - 展示成功率上升、value_loss 分化
- **幻灯片**：失败分析堆叠柱状图 — baseline 三个随机种子
  - lost=58, near_miss=30, bad_stop=5
- **幻灯片**：消融实验结果表
  - baseline → stop_aware → 5e7，含 SR/SPL/DTG
- **屏幕录制**：一个失败 episode 的回放
  - 一个 lost episode 的俯视轨迹（DTG 10m+）
  - 与一个成功轨迹并排对比

### 第三部分：真实机器人演示（3 分钟）⭐
- **视频**：机器人硬件概览
  - 展示 S100 底盘、Jetson Orin Nano、Astra S 相机
- **屏幕录制**：终端启动流程
  - 7 个终端同时启动（加速播放）
- **视频**：机器人导航 — 完整无剪辑镜头
  - 发布前方 1m 的目标点
  - 机器人转向、前进、在目标点停下
  - 终端显示："Goal reached! dist=0.XXm < 0.2m"
- **视频**：用 5e7 模型重复演示（如果两个模型都能正常运行）

### 第四部分：失败案例分析（1 分钟）
- **并排对比**：
  - 仿真：near_miss episode（DTG 0.22m，机器人就在目标旁边，但没有 STOP）
  - 真实：一次失败尝试（如有拍摄到）或仿真 lost episode
- **幻灯片**：Stop-Aware Reward 如何解决这个问题
  - 改进前：agent 在 0.22m 处继续移动 → 超时
  - 改进后：agent 在 0.19m 处调用 STOP → 成功

### 第五部分：总结（1 分钟）
- **幻灯片**：最终结果表
  - 仿真：0.845 → 0.890 → 0.945
  - 真实：baseline ✅, 5e7 ✅
- **幻灯片**：经验总结
  - Stop-Aware Reward 简单且有效
  - 增加训练步数 > 超参数调优
  - Habitat → 真实机器人 是可行的
- **幻灯片**：本仓库链接 + 联系方式

## 工具

- 屏幕录制：OBS Studio
- 机器人拍摄：手机相机（1080p）
- 剪辑：DaVinci Resolve / 剪映
- 幻灯片：PowerPoint / Google Slides（导出为图片用于视频）

## 提示

- 无剪辑的导航镜头是最重要的证据 — 不要裁剪或加速
- 将终端画面与机器人并排展示，或使用画中画
- 如果相机拍到了失败案例，保留它 — 比只展示成功案例更有说服力
- 结束时将仓库 URL 显示在屏幕上
